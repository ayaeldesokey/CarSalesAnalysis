
# Car Sales Analysis Dashboard

An interactive car sales dashboard built using **Microsoft Excel**.

##  Tools
- Excel
- Pivot Tables & Pivot Charts
- Data Cleaning
- Slicers

## Dashboard
The dashboard analyzes:
- Total Sales & Cars Sold
- Average Car Price & Customer Income
- Sales by Company
- Dealer Performance
- Body Style & Car Color
- Engine & Transmission Types
- Top Models
- Sales Trends Over Time
